## Project Overview

This project explores the factors most strongly associated with student graduation, continued enrollment, and dropout using the Predict Students' Dropout and Academic Success dataset from the UCI Machine Learning Repository.

The analysis was completed using Python and focuses on exploratory data analysis, visualization, and data storytelling.

## Objectives

- Explore student outcome patterns
- Evaluate the quality and structure of the dataset
- Investigate financial and academic factors associated with student outcomes
- Create clear visualizations
- Communicate findings to a general audience

## Tools Used

- Python
- pandas
- matplotlib
- Jupyter Notebook
- Visual Studio Code

## Dataset

- Source: UCI Machine Learning Repository
- Records: 4,424
- Variables: 36
- Outcome categories: Graduate, Dropout, and Enrolled

## Key Findings

- Students whose tuition fees were not current had substantially higher dropout rates.
- Debtor status was associated with lower graduation rates.
- Scholarship recipients had higher graduation rates.
- Early academic performance strongly distinguished graduates from students who dropped out.
- Broad economic indicators showed relatively small differences across student outcome groups.
